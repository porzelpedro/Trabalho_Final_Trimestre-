# Empório do Café ☕

## Descrição do projeto

O Empório do Café é um site de comércio eletrônico demonstrativo de cafés especiais, desenvolvido com HTML, CSS e JavaScript. O projeto permite visualizar produtos, pesquisar cafés, adicionar itens à sacola, escolher planos de assinatura e simular a finalização de pedidos.

## Como executar

1. Baixe ou clone o repositório do projeto.
2. Abra a pasta no Visual Studio Code.
3. Verifique se a pasta `img`, que contém as imagens utilizadas no site, está presente.
4. Abra o arquivo `index.html` em um navegador para acessar a página inicial.

O projeto funciona localmente no navegador, sem necessidade de instalação de dependências.

**Observação:** o checkout é apenas demonstrativo e não realiza pagamentos reais.
